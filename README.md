Swift Static implements the makefun-site 1.0.0 front matter, Markdown and template dialects with no runtime dependencies.

## Run it

Use Node.js 22. The input is a JSON array of cases with an input object containing site, templates and files. The output contains one path-to-text object per case, in order.

```sh
node main.ts cases.json answers.json
```
